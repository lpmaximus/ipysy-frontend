## Contexto

O IPYSY precisa de métricas de produto para entender comportamento dos usuários,
tráfego de aquisição e performance das páginas desde o lançamento da fase Coming Soon.

A equipe avaliou as seguintes alternativas:

| Alternativa | Custo | Privacidade | Esforço | Decisão |
|-------------|-------|-------------|---------|---------|
| **Google Analytics 4** | Gratuito | Anonimização automática de IP | Baixo | ✅ **Escolhido** |
| Plausible Analytics | Pago (~€9/mês) | Cookieless, GDPR nativo | Baixo | ❌ Custo |
| PostHog (self-hosted) | Gratuito (infra própria) | Total controle | Alto | ❌ Complexidade |
| Sem analytics | — | — | — | ❌ Sem dados |

---

## Decisão

Integrar **Google Analytics 4** usando a lib oficial do Next.js 15:
**`@next/third-parties/google`** — componente `<GoogleAnalytics>`.

**Measurement ID de produção**: `G-HPE889SHK4`

---

## Justificativa

1. **Performance**: `@next/third-parties` carrega o script `afterInteractive` — não impacta Core Web Vitals (LCP, FID, CLS)
2. **Oficial**: mantida pela equipe do Next.js, integração nativa com o App Router
3. **Gratuito**: sem custo adicional para o estágio atual do produto
4. **Condicional**: GA só carrega quando `NEXT_PUBLIC_GA_ID` está definido — dev/CI não enviam dados
5. **Futuro**: base para GA4 Audiences → remarketing e análise de funil de conversão

---

## Implementação

```tsx
// src/app/layout.tsx
import { GoogleAnalytics } from '@next/third-parties/google'

{process.env.NEXT_PUBLIC_GA_ID && (
  <GoogleAnalytics gaId={process.env.NEXT_PUBLIC_GA_ID} />
)}
```

```bash
NEXT_PUBLIC_GA_ID=G-HPE889SHK4  # produção (PROD_ENV secret)
NEXT_PUBLIC_GA_ID=               # dev/CI (GA desativado)
```

---

## Consequências

### Positivas
- Dados de tráfego disponíveis desde o dia do lançamento
- Relatório Real-Time para acompanhar campanhas de aquisição
- Zero impacto em performance (carregamento assíncrono pós-interação)

### Negativas / Riscos
- GA4 usa cookies de terceiros — requer banner de consentimento (LGPD) antes de Sprint 2
- Dados são enviados para servidores do Google — não há controle total dos dados

---

## Conformidade LGPD

**Fase atual (Coming Soon)**: aceitável sem banner — página pública, sem dados pessoais.  
**Sprint 2+**: implementar banner de consentimento (cookie consent) antes de qualquer tela autenticada.

Referência: **LGL-002** — Política de Privacidade iPYSY.
