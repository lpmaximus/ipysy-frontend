## 🔑 Restrições Críticas para o Frontend

> Estas regras NÃO podem ser violadas em nenhuma tela.

1. **LGPD/GDPR/CCPA**: Aceite dos Termos de Uso e Privacidade obrigatório no onboarding (LGL-001)
2. **Disclaimer financeiro**: A plataforma **não envolve natureza financeira** — exibido claramente (ADR-016)
3. **Usuário mínimo 18 anos**: Verificação e bloqueio no onboarding
4. **Não exibir `thumbnail_key`**: Apenas `thumbnail_url` pode ser exibida ao usuário
5. **Não exibir `X-Data-Usage-Policy`**: Header exclusivo para B2B interno — nunca ao usuário final
6. **Token de acesso**: Apenas em memória Zustand — **JAMAIS** em localStorage, sessionStorage ou cookie
7. **Source maps**: Removidos do artefato de produção — gate automático no CI (ADR-017)
