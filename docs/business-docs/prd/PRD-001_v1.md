# PRDs — Produtos iPYSY

Este documento consolida os **Product Requirements Documents (PRDs)** dos três produtos do ecossistema iPYSY, conforme definido no ADR-006.

Os PRDs são **camada de produto e experiência**, não alteram nem interferem no **CORE IPYSY-v3.1**.

# PRD — iPYSY Free

## 1. Visão do Produto

O iPYSY Free é um produto completo de **leitura, compreensão e aprendizado** sobre eventos probabilísticos. Seu papel é formar base de usuários, gerar liquidez informacional e criar confiança na plataforma.

## 2. Público-alvo

* Usuários curiosos por dados e contexto
* Estudantes, analistas iniciantes, profissionais exploratórios
* Usuários que desejam entender eventos antes de operar

## 3. Objetivo Principal

Permitir que o usuário **entenda o mundo probabilístico** de forma clara, confiável e gratuita.

## 4. Funcionalidades Incluídas

* Acesso a todos os eventos públicos
* Visualização de probabilidades agregadas
* Histórico resumido de eventos
* Dashboard simples com KPIs agregados
* Rankings (diário, semanal, mensal e histórico)
* Leitura de comentários públicos (read-only)
* Leitura de insights institucionais (read-only)
* Favoritar eventos
* Alertas básicos

## 5. Funcionalidades Excluídas

* Criação de comentários
* Criação de insights
* Simulações e backtesting
* Exportação de dados
* Selo de reputação
* Criação de eventos

## 6. Experiência do Usuário

* UX simples, limpa e educativa
* Zero sensação de produto "capado"
* Upsell contextual e não intrusivo

## 7. Métricas de Sucesso

* Ativação
* Retenção D7 / D30
* Eventos visualizados por sessão
* Leitura de insights
* Conversão para Premium

# PRD — iPYSY Premium

## 1. Visão do Produto

O iPYSY Premium é voltado ao **operador individual**, que deseja tomar decisões melhores e **comprovar competência analítica** por meio de histórico real.

## 2. Público-alvo

* Analistas independentes
* Profissionais orientados a dados
* Usuários avançados do iPYSY Free

## 3. Objetivo Principal

Oferecer vantagem analítica e permitir **prova social verificável** de habilidade probabilística.

## 4. Funcionalidades Incluídas

* Dados em tempo real
* Dashboard avançado
* Histórico completo de eventos
* Simulações e cenários
* Backtesting
* Alertas inteligentes
* Rankings com destaque
* Métricas detalhadas de performance
* Criação de comentários em eventos públicos
* Participação em threads
* Geração de Selo de Reputação iPYSY
* Exportação limitada e certificada (QR Code + verificação pública)

## 5. Funcionalidades Excluídas

* Criação de insights institucionais
* Criação de eventos
* Acesso à API
* Influência institucional

## 6. Experiência do Usuário

* Sensação clara de poder analítico
* Feedback constante de performance
* Forte incentivo à recorrência (ranking + selo)

## 7. Métricas de Sucesso

* Frequência de uso
* Uso de simulações
* Geração de selos
* Ranking médio
* Retenção
* Upgrade para Business

# PRD — iPYSY for Business

## 1. Visão do Produto

O iPYSY for Business é uma **infraestrutura de inteligência probabilística multi-domínio**, atuando como catalisador de dados e sinais sobre eventos futuros.

## 2. Público-alvo

* Fundos de investimento
* Consultorias estratégicas
* Empresas de energia, agro, saúde, tecnologia
* Mídia especializada
* Instituições de pesquisa

## 3. Objetivo Principal

Permitir que organizações **consumam, cruzem e produzam inteligência** baseada em eventos probabilísticos confiáveis.

## 4. Funcionalidades Incluídas (gerais)

* Acesso completo a eventos públicos
* Dados históricos completos
* Dashboards institucionais
* Análise cross-domain
* Leitura de comentários como sinal qualitativo

### Pacote Starter

* Dashboards institucionais básicos
* Acesso ampliado a dados históricos
* Consumo avançado de insights
* Criação limitada de eventos (sob políticas iPYSY)

### Pacote Pro

* Criação de insights institucionais
* Publicação de análises estruturadas
* Criação de eventos públicos e privados
* Métricas de impacto
* Integração via API

### Pacote Enterprise

* API completa
* Webhooks
* Multiusuário (times)
* SLAs
* Exportação avançada
* Possibilidade de white-label (futuro)

## 5. Funcionalidades Excluídas

* Uso de comentários como canal oficial de publicação
* Bypass do Core Matemático

## 6. Experiência do Usuário

* UX orientada a decisão estratégica
* Transparência metodológica
* Governança clara

## 7. Métricas de Sucesso

* Volume de dados consumidos
* Insights publicados
* Engajamento gerado
* Impacto no consenso
* Retenção e expansão de contrato

# Declaração Final

Os PRDs definem experiência, valor e escopo dos produtos iPYSY.\
Nenhum PRD altera ou interfere no CORE IPYSY-v3.1.

Este documento habilita desenvolvimento, monetização e escala do iPYSY com segurança técnica e clareza estratégica.
