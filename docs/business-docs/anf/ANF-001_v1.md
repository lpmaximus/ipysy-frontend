# 📄 1. Contexto Estratégico

A L2Tech Inc. é uma empresa de tecnologia constituída como Delaware C-Corp, cujo propósito é construir infraestrutura de inteligência preditiva baseada em reputação. Não é um produto — é uma empresa com múltiplos produtos que compartilham um ativo central: o método de indexação de julgamento humano calibrado.

Este documento formaliza a estratégia de estruturação jurídica e de captação de capital para o ecossistema L2Tech, substituindo o documento informal de mesmo escopo gerado em março de 2026. O ANF-001 compõe o acervo técnico oficial da empresa e será versionado em conjunto com os ADRs e EVTs.

## 1.1 Tese de Empresa

> **A L2Tech resolve um problema que nenhuma empresa resolveu bem até agora: como transformar julgamento humano em sinal confiável para decisões de alta consequência.**

Os três produtos da L2Tech são expressões diferentes dessa tese única:

| **Produto**      | **Domínio**                                        | **O que entrega**                                                                        |
| ---------------- | -------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **iPYSY**        | Inteligência preditiva coletiva para eventos       | IGCI: índice de consenso calibrado por reputação sobre eventos de conhecimento geral     |
| **DataPulse**    | Inteligência preditiva de restrições em projetos   | DRI: índice de risco de gargalo em projetos de infraestrutura e project finance          |
| **Decision OS**  | Camada horizontal de explicação narrativa          | Traduz qualquer índice L2Tech em cenários acionáveis com drivers identificados (ADR-011) |

O IGCI do iPYSY e o DRI do DataPulse são variações do mesmo conceito: índices probabilísticos que ponderam contribuições humanas pela confiabilidade histórica do contribuidor. Esse é o ativo real da L2Tech, não cada produto individualmente.

## 1.2 Sequenciamento de Produtos

O sequenciamento não é paralelo — é deliberadamente serial para concentrar execução e construir track record antes de escalar o ecossistema:

| **Fase**          | **Produto**    | **Papel estratégico**                                                                                                                                     |
| ----------------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Agora**         | iPYSY          | Produto em produção. Prova a tese central da L2Tech. Gera os primeiros dados reais de consenso calibrado. Ponto de entrada da empresa no mercado.         |
| **Pós-tração**    | DataPulse      | Segundo produto com proposta de valor autônoma (EVT v4 maduro). Desenvolvido após o iPYSY ter track record suficiente para validar a metodologia central. |
| **Emergente**     | Decision OS    | Camada que emerge naturalmente quando os dois produtos anteriores tiverem dados reais para explicar. ADR-011 já formalizado arquiteturalmente.            |

# 📄 2. Estrutura Jurídica — Delaware C-Corp

A decisão de constituir a L2Tech Inc. nos EUA como Delaware C-Corp não é uma escolha jurídica — é uma decisão estratégica que reposiciona completamente o universo de captação disponível.

## 2.1 Impacto da Estrutura Delaware

| **Categoria**                | **❌ Perde (CNPJ era opção)**        | **✅ Ganha (Delaware abre)**                         |
| ---------------------------- | ----------------------------------- | --------------------------------------------------- |
| Capital público não-dilutivo | FINEP subvenção R\$200k--1M+        | —                                                 |
| Programas gov. aceleração BR | SEED MG, Inovativa BR, SEBRAE Inova | —                                                 |
| Aceleração global top-tier   | —                                 | YC (US\$500k), Techstars, 500 Global                |
| Anjos + plataformas EUA      | —                                 | AngelList Reg D livre, média US\$94k/check          |
| Equity Crowdfunding EUA      | —                                 | Wefunder, Republic, StartEngine (até US\$5M Reg CF) |
| VCs LatAm com tese global    | —                                 | Kaszek, Monashees, Canary, Valor Capital            |
| Pool de capital disponível   | ~R\$15--30M BR (limitado)           | US\$18B+ seed EUA (2025)                            |
| Valuation benchmark          | Referência local                    | Referência Silicon Valley (3--5× maior)             |

## 2.2 Estrutura Dual HoldCo/OpCo (Opcional)

A estrutura padrão do ecossistema global combina holding americana para captação com subsidiária operacional brasileira para contratar CLT, emitir NF e acessar editais públicos no futuro.

| **Aspecto**             | **L2Tech Inc. (Delaware HoldCo)**    | **L2Tech Ltda. (BR OpCo — opcional)**                                                                                          |
| ----------------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| Função                  | Holding + captação de capital        | Operação local, NF, contratos CLT                                                                                              |
| Captação                | VCs americanos, AngelList, Reg CF    | Editais BR futuros (se abrir)                                                                                                  |
| Quando abrir BR OpCo    | Sempre (já existe)                   | Apenas se precisar de CLT ou edital gov.                                                                                       |
| Custo extra             | —                                    | ~R\$2--5k/ano (contabilidade, CNPJ)                                                                                            |

> **Recomendação:** Não abrir OpCo BR agora. Priorizar tração e primeira rodada. A OpCo pode ser criada em 6--12 meses se houver necessidade de CLT ou crescimento do mercado BR.

# 📄 4. Canais Prioritários de Captação

## 4.1 Y Combinator — Canal de Máxima Alavancagem

O YC é o canal de maior alavancagem disponível para a L2Tech. Não apenas pelo capital (US$500k), mas pelo brand equity de 'YC company' que abre portas automaticamente com qualquer fundo de Seed a Series B globalmente.

| **Parâmetro**           | **Detalhe**                                                                         |
| ----------------------- | ----------------------------------------------------------------------------------- |
| Investimento padrão     | US\$500.000 por empresa aceita                                                      |
| Estrutura               | US\$125k via SAFE post-money por 7% + US\$375k via SAFE uncapped MFN                |
| Taxa de aceitação       | 1,5—2% (mais seletivo que Harvard — 20—40k inscrições/batch)                        |
| Elegibilidade Delaware  | ✅ YC aceita US, Canada, Cayman e Singapore corps. Delaware é o formato preferido    |
| Próximo batch aplicável | Summer 2026 (Jun—Ago). Deadline de inscrição: ~abril 2026. Ação imediata requerida. |
| Pós-programa            | Acesso vitalício à rede YC (9.000+ alumni), Bookface, 50k+ investors DB             |
| Vantagem crítica        | 'YC company' abre portas para qualquer fundo de Seed a Series B globalmente         |

* Taxa de aceitação de 1,5—2% é real, mas founders LatAm com produto funcional e equipe técnica forte têm odds melhores que a média
* 40% das empresas aceitas no YC são pré-receita — não é preciso esperar PMF completo para aplicar
* Founders podem morar no Brasil e fazer o batch em SF por 3 meses — visto não é bloqueio graças ao programa de imigração do YC
* Techstars (US\$120k / 6%) e 500 Global (US\$150k / ~5%) são backups válidos se YC não aceitar no primeiro batch

## 4.2 Anjos Americanos — AngelList e Redes

| **Parâmetro**           | **Detalhe**                                                                          |
| ----------------------- | ------------------------------------------------------------------------------------ |
| Elegibilidade           | ✅ Exclusivo para Delaware C-Corps dos EUA (zero custo de setup para Delaware)        |
| Ticket médio            | US\$94.000 por check via plataforma (2021—2025)                                      |
| Faixa de captação       | US\$100k — US\$2M+ por rodada (Seed e Early Series A)                                |

* TAM global (não apenas brasileiro) — mostrar o mercado endereçável em US\$. Preditores calibrados e inteligência coletiva são mercados globais
* Unique Insight — por que você sabe algo que outros não sabem? A L2Tech: o método de indexação de julgamento humano calibrado é mais valioso que qualquer produto individual

# 📄 9. Conclusão

> **A Delaware C-Corp não é uma limitação — é um upgrade estratégico que posiciona a L2Tech para competir pelo maior pool de capital de risco do mundo.**

O caminho saiu de 'fomento público + crowdfunding nacional' para 'anjos americanos + YC/Techstars + VC LatAm global'. O timeline é mais longo em alguns casos, mas o ticket disponível e o valuation de referência são significativamente maiores.

A narrativa para o investidor é clara: a L2Tech é a empresa que transforma julgamento humano em índices confiáveis para decisões de alta consequência. O iPYSY é o produto que prova essa tese — está em produção, tem backend funcional (18 microserviços, Core v3.1 imutável e auditável), e está gerando os primeiros dados reais. O DataPulse é o segundo produto com EVT próprio maduro. O Decision OS é a camada que une os dois.

Três produtos, uma tese. Uma empresa, um ativo central: o método de indexação de julgamento humano calibrado. Esse é o pitch da L2Tech.
